# PseudoCraft — Frontend (GitHub Pages)

Folder ini adalah folder yang di-`git init` (harus terlihat `index.html`, `css/`, `js/` saat `ls`/`dir`).

1. Buka `js/config.js` → isi `GAS_URL` dengan URL Web App Apps Script (`.../exec`).
2. Opsional: isi `window.TUJUAN` di `js/materi.js` dengan teks tujuan pembelajaran resmi.
3. Push ke GitHub dan aktifkan Pages. Langkah lengkap: lihat `PANDUAN-INSTALASI.md`.

Backend (`Kode.gs`, `appsscript.json`) TIDAK termasuk di sini — dipasang di Google Apps Script.
